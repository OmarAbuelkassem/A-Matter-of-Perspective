## About This Project

This blog is built using my personal articles, configurations, and content. The underlying technical architecture is based on the popular open-source template [Tailwind Next.js Starter Blog](https://github.com/timlrx/tailwind-nextjs-starter-blog) by timlrx.

### Tech Stack & Features

- **Framework:** Next.js (Static Export Deployment)
- **Styling:** Tailwind CSS (with built-in dark mode)
- **Content Management:** Contentlayer (Markdown & MDX parsing)
- **Deployment:** Automated via GitHub Actions to GitHub Pages
